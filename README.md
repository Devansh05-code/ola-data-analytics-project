🚖 Ola Data Analytics Dashboard

📊 Project Overview-

This is an end-to-end data analytics project based on ride-booking data (Ola-like use case).
The project focuses on extracting, analyzing, and visualizing data to generate business insights related to bookings, cancellations, revenue, and customer behavior.

🔄 Project Workflow

🔹 1. Data Extraction (SQL)

Queried large datasets
Cleaned and transformed data
Handled missing values

🔹 2. Data Analysis (Excel)

Performed EDA (Exploratory Data Analysis)
Used Pivot Tables & formulas
Summarized key metrics

🔹 3. Visualization (Power BI)

Built interactive dashboards
Created KPIs:
Total Bookings
Success Rate
Cancellation Rate
Revenue
Added slicers for filtering

📈 Key Insights

📅 Peak booking hours identified

❌ Cancellation trends analyzed

💳 Payment mode distribution (Cash vs UPI)

📍 Location-wise demand patterns
